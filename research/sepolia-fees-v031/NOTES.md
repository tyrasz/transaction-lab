# Standalone Sepolia fee helpers

The two fee helpers now accept an explicit trusted numeric chain selector: `ethereumBlobContext(header, chainId = 1)` and `ethereumFeePlan(request, header, chainId = 1)`. Only mainnet `1` and Sepolia `11155111` are accepted. Request/header chain claims do not select the network. Existing callers still use the mainnet default; this packet does not wire or enable Sepolia execution, the HTTP API, parent validation or query execution.

The pinned Sepolia schedule is finite. Cancun activates at 1706655072, Prague at 1741159776, Osaka at 1760427360, BPO1 at 1761017184, BPO2 at 1761607008 and Amsterdam at 1791294816. Amsterdam inherits BPO2: 14 target and 21 maximum blobs per block, six maximum per transaction, 131072 gas per blob and update denominator 11684671. The current header's excess blob gas determines the exact integer price, whose minimum is one wei per blob gas. EIP-7918 changes the parent-to-child excess transition; it does not add a reserve-price clamp to this calculation. Header hash binding does not prove consensus, finality, body correctness, sidecar validity or parent excess progression.

Amsterdam fee planning admits a preliminary base bound of 12000 gas. The exact transaction still needs the independently calculated maximum of intrinsic gas and calldata floor: an empty self-call starts at 12000, a distinct zero-value recipient at 15000, a value transfer at 21000, and creation at 24000 before initcode charges. Data, access lists, authorizations and runtime state charges remain relevant. This helper does not duplicate those checks or claim that passing its 12000 bound makes a transaction executable. The local five-million gas ceiling is unchanged. All valid mainnet result shapes, the 21000 preliminary mainnet bound and `ethereumFeePlan({}, null) === null` are preserved.

The copied logs retain 18 passing pure fee controls (seven new network groups plus eleven existing fee groups) and five passing network/header controls. They cover the unchanged saved Sepolia header, before/at/after boundaries for both networks, exact inherited parameters, transaction versus block limits, malformed and hostile selectors/fields, exact fee arithmetic and complete mainnet output-shape parity. No VM, Geth target or RPC was executed for this packet. These are arithmetic and admission controls, not independent-client execution evidence.

The peer review found no blocker and requested no changes. It checked source and pinned references without starting concurrent tests during the root regression run. Root separately reported 798 engine and 701 application tests passing; their logs are outside this packet. `review.json` distinguishes those reported results from the copied pure-test logs.

`source-check.json` binds the three released files and lists exact local paths, SHA-256 hashes and line anchors for the pinned Geth, EthereumJS, trusted network helper and retained header provenance. `manifest.json` covers every packet file other than itself. This is a supplementary source/test record, not a self-contained runtime archive or a new prospective coverage sample.

# Six creation-attempt development controls

This is a fixed synthetic comparison of the current proof-backed isolated local executor and the pinned independent Geth 1.17.10 transition tool. It is development evidence, not population accuracy, mainnet/Sepolia chain state, consensus attestation, public HTTP API admission, or a real signed wallet action. The product receives an unsigned request at a synthetic proof-authenticated Amsterdam Sepolia header. Geth receives the corresponding synthetically signed type-2 transaction, sender nonce 1, chain 11155111, gas 5,000,000, caps 13/3, base fee 7, value zero, and empty calldata. No RPC/network, package installs, retries, adaptation, or real keys are used.

The six cases are declared in order before either client runs:

1. `repeated_create2`: two CREATE2 attempts, value 5, one successful constructor and one collision.
2. `initial_nonce_collision`: CREATE, value 5, preexisting destination nonce 3 and balance 17.
3. `initial_code_collision`: CREATE2, value 5, preexisting destination nonce 0, STOP code, balance 17.
4. `constructor_revert`: CREATE constructor writes storage then REVERT; creator nonce remains but endowment/storage revert.
5. `parent_rollback`: successful CREATE2 followed by collision, then root REVERT.
6. `reentrant_creation`: the factory creates, calls a helper which reenters and creates, then creates again after return.

These reuse the exact released synthetic creation fixture builders. Original allocations/roots are retained. Before any target run, both sides get identical additional nonce-1, zero-balance, STOP-code, empty-storage rows at `0x00000961ef480eb55e80d19ad83579a64c007002`, `0x0000bbddc7ce488642fb579f8b00f3a590007251`, `0x0000bff46984e3725691fa540a8c7589300d8282`, and `0x000064d678505ad48f8ccb093bc65613800e8282`. Pinned Geth Amsterdam post-block request processing requires code at these four system contracts. This is disclosed synthetic scaffolding, not deployed chain state. Geth performs system processing; the local product runs the transaction only. The comparator requires unchanged scaffold rows and no requests. Beacon/history targets are absent, withdrawals empty, reward -1; no tested path uses BLOCKHASH. Number, timestamp, coinbase, gas limit, randomness, base fee, slot number and the exact inherited current excess-blob-gas context are bound explicitly to the same header/environment. Storage allocation words are normalized to 32 bytes before freeze.

`freeze` must use a fresh, non-reused directory. It archives exact source bytes for the product runtime, isolated parent/worker, new creation observer/validator, fixture helper imports, harness, both complete dependency trees, Node identity, and pinned Geth binary/build/source/dependency manifests. Source provenance is the exact working snapshot plus repository HEAD, not an assertion that uncommitted changes belong to HEAD. The archived manifest lists every file/mode/symlink. Copies are read back and compared with live sources at freeze. Interpretation sources are authenticated against the pinned Geth source inventory. Input construction signs and builds initial MPT/header roots only; preparation controls never execute either target.

The run must be the archived driver and requires an external plan SHA. Every dispatch rechecks source, Node, binary, input and saved-artifact identities. First six separate bounded Node workers each run `executeIsolatedEthereumCall` with the same declared request/header, only an immutable prestate proof/code provider, and the production 5M admission limit. They retain the complete actual isolated attempt, exact parsed proof/code requests/replies, timing, broker evidence, creation-attempt ledger and net changes. No Geth result or expected poststate enters this phase. A completed, closed/drained isolated result has its changes applied to a fresh independently loaded MPT; this supplies the product full-root expectation. No full-VM execution supplies an expected answer. Every raw product process result is durably sealed before any Geth process starts; non-completed local attempts are retained and never converted to expectations.

Then exactly six `evm t8n` processes use each exact saved initial allocation, environment and signed RLP transaction body, forced Amsterdam/chain 11155111/reward -1. Raw alloc/result/body and JSON opcode/call-frame traces remain retained. The five automatic comparison fields are full state root, internal log hash, receipt success/failure, charged receipt gas, and block gas `max(regular,state)`. Geth separate gas dimensions are not exposed by this output; product dimensions are used only to form that maximum. Return bytes, internal error strings and exact per-attempt traces are retained locally but are not automatic independent-client channels. All cases currently commit no logs, so log-hash agreement is explicitly empty-log coverage. Trace files support subsequent artifact-only inspection; receipt agreement alone never establishes identical internal execution paths.

Bounds: at most six product wrapper workers, six nested isolated children and six Geth targets; 15 seconds per process, 180 seconds total with wall and monotonic clocks/reversal/terminal checks; Node heap 256 MiB; combined stdout/stderr 2 MiB per process; eight flat output entries per Geth call, 4 MiB per file, 48 MiB total output. Nested isolated worker explicitly tightens wall time to 10 seconds, input/execution time to 8 seconds, request time to 1 second, and drain/kill wait to 1 second each; every returned attempt binds child closure/drain, including unavailable attempts; the outer process bound is an additional limit, not a claim of OS process-tree isolation. A terminated outer worker with incomplete evidence is unavailable; no completed result is inferred. All output entries are stat-counted before reading. Oversized/nonfile output remains as explicit unhashed metadata and invalidates packet usability. Unknown outputs, rejected/malformed responses and nonzero exits remain unavailable. Bounds, clock reversal, source/artifact mutation or buffer overflow invalidate the packet; retained diagnostic row counts cannot override `comparisonsUsable:false`. All six denominator slots survive interruption. No failed capture or partial freeze is overwritten.

The protocol is adapted from the already reviewed `research/amsterdam-state-gas-diagnostic-v031` harness, with target-free controls for declarations/signatures/context, fabricated positive and negative comparison shapes, raw/process/time/output bounds, durable seals, and source closure. Parent source-stable signal and preparation peer review precede freeze and the single bounded dispatch.

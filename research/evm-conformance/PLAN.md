# Official state-test conformance slice v1

This is a deterministic development slice of the official `ethereum/execution-specs` release `tests@v21.0.2`, commit `e27f097ec7b3e6e8ee9c2c1873c183e8f7da7a6e`. It evaluates the separately installed EthereumJS 10.1.3 full-transaction dependency stack. It is not a random transaction cohort or a product accuracy estimate.

The official asset has 939,189,561 compressed bytes and SHA256 `e2fa7ea2ea516459f9ab92284b2927892f318f4e1f78ca802cb05a6c3b479ed9`; the downloaded bytes match the publisher digest. The initial 8 GiB streamed scan stopped before state tests and remains retained as incomplete. A pre-execution second scan, bounded to 64 GiB expanded / 900 seconds, completed at 15,460,362,240 expanded bytes and 46,560 members. Only 55 candidate source files were retained (each at most 8 MiB; aggregate cap 512 MiB). The complete archive remains temporary, outside git.

The final `selection.json` identifies all 32 vectors before execution: 12 nested-call cases; three each of rollback warmth, SSTORE, transient storage, and refunds; and eight explicit non-KZG precompile cases. Files and IDs sort lexically and post indexes numerically, with round-robin selection across files inside each fixed group. Resource filtering inspects fixture structure only. The earlier proposal before storage subquotas is retained and was never executed. No execution outcome influenced selection.

The signed gas limit is preserved exactly. Before selection/execution, the initial 5,000,000 harness ceiling was amended to 16,777,216 because the official call-chain vectors use Osaka's maximum; the product limit was not changed. Other limits are 32 KiB calldata, 128 prestate accounts, 1,024 prestate storage slots, 8 MiB per source file, 512 MiB child heap, 1 MiB combined child output, 10 seconds per child and six minutes overall. Every selected row is retained, including timeout, unavailable, mismatch or unattempted outcomes. There are no retries, replacements or alternate expected values.

The archive binds all runtime files, locked dependencies, selected original JSON files, harness source, Node executable and final selection. Each child executes from that archive; no product module or provider output supplies initial state. Full signed admission uses actual fork rules, signature, nonce, balance and fee checks. The oracle is the official poststate root/logs hash and available receipt fields. Receipt gas is independently expected for these selected vectors; raw VM execution outcomes and errors are retained. Constructor errors outside the implemented closed adapter remain unavailable, not an assumed expected exception match.

Primary sources: [official fixture release](https://github.com/ethereum/execution-specs/releases/tag/tests@v21.0.2), [EthereumJS VM 10.1.3 release](https://github.com/ethereumjs/ethereumjs-monorepo/releases/tag/%40ethereumjs%2Fvm%4010.1.3). Exact registry metadata, integrity-verified package tarballs and acquisition failures are retained in `acquisition/`.
